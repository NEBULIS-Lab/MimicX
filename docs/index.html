Learning the motion.
Refining how it is learned.

MimicX learns humanoid motion from human video. A policy's execution reveals which transitions and body regions need attention, turning tracking failures into targeted changes to training supervision.

The loop coordinates motion-tracking objectives and practice, then verifies each update through repeated execution. Better execution, not a larger training reward, determines which policy is retained.

Execution becomes supervision

A registered motion reference establishes the task. Policy feedback determines how that task is practiced and rewarded.

01

Diagnose execution

Find difficult time windows and rank local limb, global body and dynamics error channels.

02

Refine supervision

Continue the accepted policy with coordinated tracking terms and failure-window replay.

03

Verify the update

Prioritize completion and execution horizon, then tracking fidelity. Retain the current policy when no candidate passes.
