# Navigation Icons

Unmodified SVGs from `lucide-static@0.468.0`, distributed through
https://cdn.jsdelivr.net/npm/lucide-static@0.468.0/icons/.
The upstream license is retained in `LICENSE`.

Icons: github, file-text, book-open, brain-circuit and database.
The brain-circuit/database icons denote policies/assets; they are not
Hugging Face brand marks. Provider names are written alongside each icon.

Navigation brand marks under `brands/` are unmodified SVGs downloaded from
[Simple Icons](https://simpleicons.org/): GitHub, arXiv, Read the Docs and
Hugging Face. The upstream CC0 license is retained in
`SIMPLE_ICONS_LICENSE.md`; product names and marks remain subject to their
respective brand guidelines.
